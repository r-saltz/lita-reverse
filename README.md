# Lita Reverse Engineering

API client for the Lita game (h5.lita.game) using Playwright with Chrome TLS fingerprinting.

## Overview

This project provides a Python script to interact with Lita game's API endpoints. The script uses Playwright with a real Chrome browser to handle WASM-based signature generation and bypass APISIX WAF rate limiting.

## Features

- Fetch ranking data (daily/weekly)
- Session initialization (`/h5/init`)
- System options retrieval
- WASM signature generation via browser context
- Chrome TLS fingerprinting to bypass bot detection

## Requirements

- Python 3.8+
- Chromium browser (automatically installed by Playwright)
- Node.js (for WASM signature generation, if not using Playwright approach)

## Installation

```bash
pip install -r requirements.txt
playwright install chromium
```

## Usage

```bash
# Fetch daily ranking (default)
python lita_fast.py

# Fetch weekly ranking
python lita_fast.py /funbit/v2/api/active/202108/rank type=weekly

# Initialize session
python lita_fast.py /h5/init

# Get system options
python lita_fast.py /funbit/v2/system/option/h5
```

## How It Works

1. Launches a headless Chrome browser via Playwright
2. Navigates to the Lita ranking page with authentication parameters
3. Waits for Vue.js app to load and WASM signature generation
4. Captures API responses or makes direct requests using the browser's authenticated context
5. Returns JSON data from the API

## Technical Details

- **Endpoint**: `https://h-api.lita.game`
- **Signature**: WASM-based `l-sign` header generated by `stable.wasm`
- **Authentication**: Requires `accessToken`, `userId`, and `proxyHeader`
- **Rate Limiting**: APISIX WAF blocks non-browser TLS fingerprints; Playwright with Chrome bypasses this

## Files

- `lita_fast.py`: Main API client
- `stable.wasm`: WASM binary for signature generation
- `requirements.txt`: Python dependencies
